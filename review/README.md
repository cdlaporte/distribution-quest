# Unit 3 review sheet

Printable review (5 problems per section, 25 total, with blank space for work) and answer key, generated from `js/problems.js`.
Regenerate with `node review/build-review.js` (needs Playwright + Chromium for the PDFs; the HTML is always written).
Use `SEED=<number> node review/build-review.js` for a different but reproducible set of problems; edit `PLAN` in the script to change which problem types appear.
